One fortune cookie line for a crypto trader who just got liquidated — a small, deterministic TypeScript program that writes the fortune to `/output/entry.txt`. The fortune opens with oracular fortune-cookie wisdom and breaks it with a rueful punchline: the trader meant to walk away, and was carried instead.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later. It writes the single fortune line to `/output/entry.txt`.
